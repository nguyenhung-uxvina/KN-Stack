# Rules for 3_Resources/ folder

Resources are things you USE, not things you STORE.

## Before creating new content
- Check: does this already exist in Galaxy or another resource?
- Check: will this be referenced within 30 days? If not → don't create.
- Insights belong in Galaxy, not Resources.

## Staleness rule
- If a resource hasn't been referenced in 3 months → suggest archive or delete
- Deep-Content-Analyzer outputs: keep only if Three Laws extracted to Galaxy

## Legacy folders
- `Books & Articles/` and `Tools & Software/` are legacy
- When using content from these folders, migrate to the appropriate new subfolder
- Do not create new content in legacy folders

## Organization
- Framework-Library/ → reusable frameworks (THỊNH, ARCHITECT, etc.)
- AI-Infrastructure/ → CLAUDE.md, prompts, MCP configs, active skills
- Technical-References/ → Pahl-Beitz, MIL-STD, ACH research, hardware specs
- Competitive-Intelligence/ → Viettel products, Vietnam defense landscape
- SOPs/ → Gate review protocol, design review checklist, documentation standards
- Templates/ → Note and project templates

## COD Classification
- Creating/organizing resources = Offload (AI)
- Deciding what to archive = Core (CEO judgment)
