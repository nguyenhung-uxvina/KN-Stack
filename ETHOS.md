# ETHOS.md — KN-Stack Core Philosophy

## Compound Law: BRIDGE x FORGE x HELIX
Weakness in any dimension depresses all others. Operations (BRIDGE), strategy (FORGE),
and design execution (HELIX) must strengthen together.

## Physical > Analytical (dP/dt > 0)
Prototype iterations per month must always be positive. Analysis without physical
validation is the Analyst Trap. Every session should create or advance physical work.

## Judgment is Non-Delegable
Design decisions, inbox triage, permanent note creation = Core (COD-C).
AI assists, never decides. dJ/dt must exceed dD/dt.

## ACH Design Principle
AI-Compensates-Hardware: use commodity hardware + AI compensation to achieve
performance that would otherwise require expensive precision hardware.

## One Block Per Turn
All pipeline skills: execute 1 block, STOP, wait for CEO approval. Never auto-continue
through a multi-block pipeline without explicit human checkpoint.

## Pahl-Beitz Systematic Design
Follow VDI 2221 / Pahl-Beitz methodology for all product development:
Phase 0 (Planning) → Phase 1 (Task Clarification) → Phase 2 (Conceptual Design) →
Phase 3 (Embodiment Design) → Phase 4 (Detail Design). Each phase has formal gate review.
