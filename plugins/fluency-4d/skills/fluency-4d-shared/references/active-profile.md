# Profile đang bật

Ba `SKILL.md` KHÔNG gọi tên file profile nữa. Chúng đọc file này để biết dùng profile nào.
Đổi người dùng = đổi đúng một dòng dưới đây, không đụng vào skill.

```
profile-workshop-x.md
```

Dòng trong khối trên là **tên file duy nhất**, nằm cùng thư mục `references/`.
Không đường dẫn, không backtick, không chú thích kèm theo.

## Luật

- File được trỏ phải tồn tại thật trong `references/` và phải mang tiền tố `profile-`.
- File được trỏ **không được còn ô `⟨CEO chốt: …⟩` nào**. Nháp chưa duyệt xong thì chưa
  được bật — bật một profile còn nháp nghĩa là chấm điểm theo tín hiệu chưa ai chốt.
- `profile-template.md` là khuôn rỗng, **không bao giờ** được bật.

## Các profile có sẵn

| File | Dùng cho | Trạng thái |
|---|---|---|
| `profile-workshop-x.md` | CEO Workshop X | dùng được |
| `profile-quan-doc.md` | Quản đốc phân xưởng | **nháp — chờ CEO chốt cờ đỏ** |
| `profile-template.md` | Khuôn để viết profile mới | khuôn rỗng |
